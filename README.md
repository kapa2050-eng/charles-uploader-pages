# charles-uploader-pages

친절한찰스업로더 앱의 공개 안내 페이지(GitHub Pages)입니다. 구글 OAuth 앱 심사에 필요한 홈·개인정보처리방침·약관 주소로 씁니다.

| 파일 | 내용 |
|---|---|
| `index.html` | 홈 — 앱이 하는 일 / 안 하는 일 |
| `privacy.html` | 개인정보처리방침 (요청 권한, 저장 위치, 삭제 방법) |
| `terms.html` | 서비스 약관 |
| `style.css` | 세 페이지가 함께 쓰는 스타일 (휴대폰 화면 대응 포함) |

문구를 고칠 때는 `privacy.html`, `terms.html`의 "최종 수정" 날짜도 같이 바꿔 주세요.
